# Kernel for Nothing Phone 2 (Pong)
##### Lineage 23.X branch - Required for build

## Setup

Clone the correct branch into **kernel/nothing/sm8475** and init submodules

You can do so by selecting the branch corresponding to your rom at the top and executing this command:
> git clone https://github.com/Sevo9128/kernel_nothing_sm8475.git -b lineage-23.X kernel/nothing/sm8475 <br>
> cd kernel/nothing/sm8475 <br>
> git submodule init <br>
> git submodule update <br>
> cd ../../..
